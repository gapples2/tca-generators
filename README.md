repository for tca-related stuff

for the main use of this generator (generating solutions for xcs):
- add a file named "func_list.txt", and copy spreadsheet columns B-G from the Apparatus Progress spreadsheet's `Function List` tab into it
- have npm installed
- enter either "node limited_use.js" for generating solutions based on what's available or "node limited_use.js min" for generating the list if restores are available
