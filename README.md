# TCA Generators

A small repository for useful scripts for The Counting Apparatus, a [discord counting game](https://discord.gg/ChmSV4XDBm).

The main function of this repository is to generate XC solutions using a curated list of functions (`./xc_solver/limited_use.js`).

It also has smaller workflows to:

- Extract Tree grid colors from a Tree grid image (`./tree_extract`)
- Generate solutions for Tree's gwa minigame (`./tree_gwa_gen`)

The XC solver in `xc_solver/` reads a file containing a manual spreadsheet export from the Apparatus Progress `Function List` tab, filters out unavailable or corrupted functions, and searches for valid solution expressions within the configured limits. The `tree_*` folders contain browser-based helper tools for the other two workflows.

## Overview

This project contains three workflows, each with a different entry point:

1. XC solution generation at `xc_solver/limited_use.js`
2. Tree grid color extraction using the browser helper at `./tree_extract/index.html`
3. Tree gwa minigame solution generation using the browser helper at `./tree_gwa_gen/index.html`

## Quick start

### XC solution generation

Prerequisites:

- Node.js installed

Instructions:

1. Create a file named `func_list.txt` in the project root.
2. Paste spreadsheet columns B-G from the Apparatus Progress `Function List` tab into that file (found [here](https://docs.google.com/spreadsheets/d/1u77PAhvEFxpSPpkWACw69_0AFFFy_lCGMk5DEHxA-gI/edit#gid=352972499)).
3. Run the generator script from the project root:

```bash
node xc_solver/limited_use.js
```

This generates solutions based on the currently available functions.

To generate the reduced/minimal list when restores or alternative options are available:

```bash
node xc_solver/limited_use.js min
```

4. Review the output in `generated.txt`.

### Tree grid extraction

Open the helper page in a browser:

```bash
./tree_extract/index.html
```

This tool helps extract relevant colors or values from a Tree grid image. The extracted data can be found in the browser console.

### Tree gwa generator

Open the helper page in a browser:

```bash
./tree_gwa_gen/index.html
```

This tool generates candidate solutions for the Tree gwa minigame.

## File dependency summary

The dependency structure for the XC solver is straightforward:

- [xc_solver/limited_use.js](xc_solver/limited_use.js) is the orchestrator. It imports the configuration and function definitions, then runs the search logic.
- [xc_solver/const.js](xc_solver/const.js) provides the numerical limits and global constants used by the generator and by [xc_solver/unary.js](xc_solver/unary.js) and [xc_solver/binary.js](xc_solver/binary.js).
- [xc_solver/func_info.js](xc_solver/func_info.js) reads [func_list.txt](func_list.txt) from the project root and exports the metadata used to decide which functions are available or invalid.
- [xc_solver/const_funcs.js](xc_solver/const_funcs.js) depends on the `unlocked` data from [xc_solver/func_info.js](xc_solver/func_info.js) to filter valid numeric values and names.
- [xc_solver/unary.js](xc_solver/unary.js) and [xc_solver/binary.js](xc_solver/binary.js) define the operation sets used by the search.
- [xc_solver/identity_funcs.js](xc_solver/identity_funcs.js) also depends on the same function metadata and is used when building output expressions and additional identity steps.
- [xc_solver/limited_use.js](xc_solver/limited_use.js) writes the final output to [generated.txt](generated.txt) in the project root, but the output is not used as an input by the generator itself.

In short, the main chain is:

`func_list.txt` -> `xc_solver/func_info.js` -> `xc_solver/const_funcs.js` + `xc_solver/unary.js` + `xc_solver/binary.js` + `xc_solver/identity_funcs.js` -> `xc_solver/limited_use.js` -> `generated.txt`
